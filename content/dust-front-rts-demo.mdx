## A useful first Demo session

Spend the first session learning the information model rather than chasing an optimized victory. Identify the objective, confirm how resource flow is represented and observe how the game communicates production problems. Test movement, selection, construction and queue controls in a low-risk area.

Then run a small controlled experiment: build one resource chain and one production line, noting which inputs are required. Add a defensive force only after confirming the economy can replace it. This produces reliable notes even if balance changes later.

## How to evaluate older gameplay videos

Prefer videos that show the menu, build date or upload date and sustained uncut gameplay. Compare two sources before turning a player's tactic into a recommendation. A video can confirm that a structure or unit appeared in one build, but not that its values remain unchanged.

Avoid using thumbnails, titles or short clips as evidence for faction balance, difficulty modifiers or unlock rules. If two sources conflict, prefer the newer official source and mention the version difference.
