- 官方 YouTube 频道直链。

## 六、网站主题色

Dust Front RTS 的世界观偏废土、工业和军事题材，建议默认使用深色主题，亮色主题作为辅助模式。

```css
/* 导航页主题色 - 亮色主题 */
--nav-theme: 82 32% 38%;       /* Dust olive */
--nav-theme-light: 82 38% 50%; /* 更浅的军用橄榄绿 */

/* 导航页主题色 - 暗色主题 */
--nav-theme: 82 32% 38%;       /* Dust olive */
--nav-theme-light: 82 38% 50%; /* 更浅的军用橄榄绿 */

/* 页面基础色 - 暗色主题 */
--background: 32 12% 10%;      /* 废土黑褐 */
--surface: 36 10% 16%;         /* 深灰棕 */
--surface-muted: 38 9% 22%;     /* 灰尘灰 */
--text-primary: 40 18% 92%;    /* 沙白 */
--text-muted: 38 10% 68%;      /* 灰尘灰 */
--accent: 20 72% 48%;          /* 警戒橙 */
--danger: 4 68% 48%;            /* 战斗红 */
```

设计建议：默认暗色；导航栏使用深灰棕；主要按钮使用军用橄榄绿；提示、警报和超级武器使用锈橙或暗红；避免通用蓝白科技风。

## 七、多语言优先级

本次新增中文后，建议支持 5 门语言，优先级如下：

1. English — `Dust Front RTS`
2. German — `Dust Front RTS`
3. Spanish — `Dust Front RTS`
4. French — `Dust Front RTS`
5. Chinese — `灰烬战争（Dust Front RTS）`

### English

首要语言。Steam、YouTube、Steam Community 和国际玩家讨论主要使用英语，且 `Beginner Guide`、`Build Order`、`Factions`、`Economy` 等关键词应优先制作英文页面。

### German

德国拥有成熟的 PC 和策略游戏用户群，适合在英文版本稳定后增加德语页面。暂未确认官方德语本地化标题，因此继续使用 `Dust Front RTS`。

### Spanish

西班牙语可覆盖西班牙和拉丁美洲玩家。建议翻译新手、阵营、经济、单位、Build Order 和 Demo 页面；主题名继续使用 `Dust Front RTS`。

### French

法国 PC 策略游戏用户较稳定，适合在英文版本之后增加法语页面。暂未确认官方法语标题，因此继续使用 `Dust Front RTS`。

### Chinese

中文社区已经出现较稳定的本地化讨论和 Demo 汉化相关内容，中文主题名可使用：

```text
灰烬战争（Dust Front RTS）
```

中文版本适合优先制作：

- Demo 下载与运行说明；
- 新手入门；
- 基地建设；
- 单位与建筑说明；
- 汉化和版本兼容提醒；
- Steam 页面信息整理。

中文版本应避免把社区汉化项目写成官方汉化，也不要把第三方补丁描述为官方内容。

### 实施顺序

```text
English → German → Spanish → French → Chinese
```

如果中文用户的 Search Console 流量、Steam 社区讨论或 YouTube 搜索表现明显高于德语、法语，可以将中文提前到第二阶段；但英文版本仍应作为基础版本优先完成。
